# From zero to production: 12 stages

Creavia goes from idea to a production service through twelve stages, each with its own deliverables and a test that
closes it; stages overlap, but none is skipped. Each roadmap phase ([../phases/](../phases/)) runs through stages 3 to
8 again for its own houses.

| | 3 Product specs | PRDs, MVP scope | [03-product-specs.md](03-product-specs.md) |
| | 4 UX | Tested wireframes | [04-ux.md](04-ux.md) |
