# Stage 3: product specs (PRDs)

**Status:** not started. **Done when:** every MVP story has acceptance criteria and a metric, and the owner signs off
the scope.

Every house or feature gets a PRD in `docs/town/prd/<house>-<feature>.md` before it is designed:

1. **Problem and evidence** (quotes from Stage 2)
2. **Who it is for** (persona, job)
3. **Goals and non-goals**
4. **User stories with acceptance criteria** ("As a creator, I can…; done when…")
5. **Objects and tools** (which objects; which registry tools it adds, with permission levels)
6. **Agent behaviour** (what its agent does at Suggest, Prepare, Do-then-tell)
7. **Edge cases and failures** (offline, platform error, revoked account, empty state)
8. **Metrics**
9. **Launch plan**

**Choosing what goes first:** score each feature on reach, pain, effort and strategic fit (feeds the loop or the moat).
**MVP:** the smallest set that lets a short-form creator run a full week in Creavia: idea, script, voice, subtitles,
post to Reels and Shorts, auto-reply to comments, see results.
