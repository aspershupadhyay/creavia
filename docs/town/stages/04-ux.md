# Stage 4: UX

**Status:** not started. **Done when:** four of five creators finish each core task without help, and first launch to
first scheduled post takes under ten minutes.

1. **Information architecture:** the ten sidebar items, what lives in each, the objects and links
   ([../town-map.md](../town-map.md)).
2. **Ten core flows:** first launch → first post; idea → scheduled Reel; comment → DM → lead; brand email → paid
   invoice; connect Instagram; invite an editor; approve an agent's work; plus three from research.
3. **Wireframes** (grey boxes) for Home, a project with its tools, Calendar, Inbox, Analytics, Money, Tasks, Settings,
   Connectors; desktop and 390 px.
4. **Content design:** plain names, short sentences, buttons that say what happens ("Schedule for 6 pm"), errors that
   say how to fix them, empty screens that teach. A voice-and-tone guide.
5. **Prototype and test:** five creators × five tasks, thinking aloud; fix what confuses two or more; test again.
