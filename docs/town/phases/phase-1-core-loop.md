# Phase 1: core loop

**Status:** not started. Needs Phase 0.
**Goal:** a short-form creator runs a full week in Creavia: idea → script → voice → subtitles → post to Reels and
Shorts → see results. Mostly VoiceBox features moved into the new structure and look.

## What ships

- [ ] **Ideas** (Juno, at Suggest): board, scripts, trends, competitor ideas, "from your best posts".
- [ ] **Create** (Bolt): voice, clean audio, subtitles, images and thumbnails, own-content download; tools inside a
      project.
- [ ] **Calendar** (Tempo): calendar, auto-posting YouTube and Instagram, post package, best time.
- [ ] **Analytics** (Lens): channel analytics, audience and timing, competitors, "why it worked" with Make this.
- [ ] **Files** (Atlas): files, share and upload links, brand kit (first version).
- [ ] **Ask Vee:** chat that acts through the registry, approvals, Tasks view, memory (first version), the crew line on
      Home.
- [ ] **Where AI runs:** own keys (BYOK) and local models; cloud GPU with per-workspace caps.
- [ ] The agent runtime (durable tasks, budgets, evals) for Juno, Bolt, Tempo, Lens, Atlas.

## Done when

- Closed-beta creators post through Creavia every week, and the week-long flow works without leaving the app.
