# Phase 1: core loop

**Status:** not started. Needs Phase 0.
**Goal:** a short-form creator runs a full week in Creavia: idea → script → voice → subtitles → post to Reels and
Shorts → see results. VoiceBox's back-end capabilities behind screens designed from scratch (no VoiceBox UI).

## What ships

- [ ] **Ideas** (Juno, at Suggest): board, scripts, trends, competitor ideas, "from your best posts".
- [ ] **Create** (Bolt): voice, clean audio, subtitles, images and thumbnails, own-content download; tools inside a
      project.
- [ ] **Calendar** (Tempo): calendar, auto-posting YouTube and Instagram, post package, best time.
- [ ] **Analytics** (Lens): channel analytics, audience and timing, competitors, "why it worked" with Make this.
- [ ] **Files** (Atlas): files, share and upload links, brand kit (first version).
- [ ] **Ask Vee:** chat that acts through the registry, approvals, Tasks view, memory (first version), the crew line on
      Home.
- [ ] **Connectors, the first 25, and your own MCP servers:** the catalog page built for about 100 (search, groups),
      the creator stack first, and "Connect an MCP server" by address and OAuth (docs/town/connectors.md).
- [ ] **Where AI runs:** own keys (BYOK) and local models; cloud GPU with per-workspace caps.
- [ ] The agent runtime (durable tasks, budgets, evals) for Juno, Bolt, Tempo, Lens, Atlas; an autonomy setting per
      routine (Suggest · Prepare · Do then tell).
- [ ] **Your page:** Vee's memory as a page you can read and edit (voice and style, audience, goals, projects, people),
      each fact linked to its source (stages/04-ux.md, pattern 4).
- [ ] **Routines:** the library by creator type, "Describe your own" → Build it; featured: Morning brief, 24-hour post
      check, Weekly content plan (pattern 7).
- [ ] **Your morning brief:** in the app, by email and as 1-minute audio; weekly free, daily paid (pattern 8).

## Done when

- Closed-beta creators post through Creavia every week, and the week-long flow works without leaving the app.
