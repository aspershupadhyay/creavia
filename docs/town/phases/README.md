# The roadmap, in phases

Phase 0 comes first because every house stands on it; then the houses open in the order creators feel them: the daily
loop, their audience, their money, everything else. No dates: each phase closes on its test. Each phase runs through
the build stages in [../stages/](../stages/) (specs → design → build → quality) before it reaches creators.
